# Service Tickets — App B (Student)

This project is an Expo React Native application. Its local JSON fixture simulates an API response so the exercise works offline.

## Run

1. Install Node.js 20.19+ and npm.
2. In this folder run `npm install`.
3. Run `npx expo start`, then open with a compatible Expo Go version or web (`w`).

The student version contains four intentional, isolated logic defects in `src/logic.cjs`.
